# Wording review for a clinician

**For:** an eating-disorder clinician (ideally FBT-trained) reviewing what Plate Together says to parents.
**Time needed:** about 20 minutes.
**How to use:** for each line, write **Keep**, **Change** (with your wording) or **Cut** in the last column, and
answer the questions in bold. Nothing here is advice the app generates; every line below is fixed text
written by the team, shown exactly as listed. The live app currently shows these drafts.

Context: parents of a teen (mostly with anorexia) log meals on a phone. A clinician linked to the family
writes the family's own plan for refused meals and a few lines to read at the table. A teen may read the
screen over a parent's shoulder.

---

## 1. The four ways a meal can be logged

Shown on every screen where a meal is logged or reviewed, for parents **and** clinicians. All four are drawn
in the same colour on purpose, so no outcome looks like a failure or a win.

| # | Word shown | Hint under it | Stored as | Keep / Change / Cut |
|---|---|---|---|---|
| 1.1 | Ate it all | All or nearly all of the plate | `okay` | |
| 1.2 | Ate some | Part of the plate | `difficult` | |
| 1.3 | Didn't eat | None of it, or left the table | `refused` | |
| 1.4 | Not served | We didn't sit down for this one | `skipped` | |

**Questions**
- **Q1.** Is "Ate some" the right bucket for a partly finished meal, or should "difficult" mean something
  else (for example, finished but with a lot of distress)?
- **Q2.** Should clinicians see these parent words, or clinical words such as "Completed / Partial / Refused"?
- **Q3.** Is "nearly all" acceptable for "Ate it all", or should completion be stricter in FBT?

## 2. Right after a meal is logged as "Didn't eat"

Screen with a soft apricot header. The steps under it come only from the family's clinician.

| # | Where | Text | Keep / Change / Cut |
|---|---|---|---|
| 2.1 | Heading | "Dinner didn't happen today." (meal name changes) | |
| 2.2 | Under heading | "That's saved. Hard meals are part of recovery, not a failure. Here is what your plan says to do now." | |
| 2.3 | Plan heading | "If a meal is refused" | |
| 2.4 | Under the plan | "Written by your clinician." | |
| 2.5 | No plan yet | "Your clinician hasn't written a plan for this yet. Ask about it at your next session, and let them know about this meal below." | |
| 2.6 | Message box | "Tell your clinician" / "Add a line (optional)" / "Send to your clinician" | |
| 2.7 | Message sent to the clinician | "Hard dinner on Thu, Nov 26 (refused)." | |
| 2.8 | Under send button | "Messages are not watched around the clock. In an emergency, call 911." | |
| 2.9 | After sending | "Sent. Your care team will see it next time they open Plate Together. This is not an emergency line." | |
| 2.10 | Bottom link | "Worried it's more than a hard meal? When to get help" | |

**Questions**
- **Q4.** Is "not a failure" helpful, or could it read as minimising a refusal?
- **Q5.** Emergency numbers are one tap away (behind 2.10) rather than shown on every refusal, because refusals
  are expected and a teen may be watching. Is that the right call?

**Example refusal plan used in demos only** (each family's real plan is written by their clinician):
1. Stay at the table. Keep your voice calm.
2. Offer the meal once more after a short break.
3. If it is still no, offer the backup on your plan.
4. Then let it go for tonight. Breakfast is a fresh start.

- **Q6.** Is this a reasonable demo example, or would you change it so it doesn't model the wrong thing?

## 4. When to get help

Shown when a parent taps "Get help" or "When to get help". Fixed text: the app never judges seriousness.

| # | Text | Keep / Change / Cut |
|---|---|---|
| 4.1 | Heading: "Call 911 now if you see" | |
| 4.2 | Fainting or collapse | |
| 4.3 | Chest pain | |
| 4.4 | Trouble breathing or a seizure | |
| 4.5 | Any talk of suicide or self-harm | |
| 4.6 | Buttons: "Call 911", "Call 988 (suicide and crisis line)", "Text 988" | |
| 4.7 | Heading: "Call your care team today if you see" | |
| 4.8 | Refusing all food and drink for a full day | |
| 4.9 | Making themselves throw up, or using laxatives | |
| 4.10 | New dizziness, feeling very cold, or a racing or fluttering heartbeat | |
| 4.11 | "General guidance only. Your clinician's own instructions come first. This app cannot tell whether something is an emergency, so if you are unsure, call." | |

**Questions**
- **Q8.** Is anything in 4.8 to 4.10 actually a "call 911 now" sign (for example, refusing fluids, or a very
  slow or irregular heartbeat)? Is anything missing (for example, compulsive exercise, signs of refeeding
  problems in the first weeks)?
- **Q9.** Should the family's own clinician be able to edit this list for their family?

Design note for the team: the "Call 911" button is red (the only red in the app) so it stands out.

## 6. The AI chat's fixed safety replies

The parent chat checks messages in code before any AI sees them. These replies are fixed, not generated.

| # | Triggered by | Reply | Keep / Change / Cut |
|---|---|---|---|
| 6.1 | Suicide, self-harm, fainting, chest pain, trouble breathing, seizure | "I'm really glad you told me. If anyone is in immediate danger, or someone has fainted, has chest pain, or is struggling to breathe, please call 911 now. For thoughts of suicide or self-harm, call or text 988 (Suicide & Crisis Lifeline) any time. I can't replace emergency help, but you can also tap SOS here and I'll let your care team know you need support." | |
| 6.2 | Purging, laxatives, not eating or drinking for a day or more | "Thank you for telling me, that sounds worrying. This is something your care team should hear about today, so please contact them directly. I can also send them an SOS from here. If things feel unsafe or you see fainting, chest pain, or trouble breathing, call 911." | |
| 6.3 | AI reply blocked (calorie, weight or diagnosis talk) | "I'm not able to help with that one. Your care team is the right person to ask. Want me to flag it for them?" | |

- **Q11.** Should not drinking at all (6.2) move up to the 911 reply (6.1)?

The AI's full instructions (the system prompts) live in `src/lib/chatService.js` and `src/lib/aiInsights.js`
and need a separate review before any clinician-facing AI ships.

## 7. Starter food ideas for a new family

A family with fewer than 8 saved foods sees a few tappable ideas for the meal they are logging. There are no
preset "safe" or "challenge" labels: the parent picks the type (Familiar, Working on, Challenge) when adding.

| Meal | Ideas shown | Keep / Change / Cut |
|---|---|---|
| Breakfast | Toast, Oatmeal, Cereal with milk, Yogurt, Banana, Scrambled eggs, Bagel, Pancakes | |
| Lunch | Turkey sandwich, Grilled cheese, Pasta, Quesadilla, Soup, Mac and cheese, Chicken wrap, Pizza | |
| Snack | Apple, Cheese and crackers, Granola bar, Pretzels, Grapes, Peanut butter crackers, Trail mix, Muffin | |
| Dinner | Pasta with sauce, Rice, Chicken, Tacos, Salmon, Burger, Potatoes, Stir fry | |

- **Q12.** Is a neutral list like this helpful for a new family, or could any suggestion feel like pressure?
  Should the family's clinician be able to set these instead?

## 8. "This meal is hard" (the calm screen)

A parent at the table taps "This meal is hard" under the Log button on Next meal. The screen shows the
clinician's own table lines one at a time, in large type, with "When to get help" always at the top. The app
adds no advice of its own: with no lines it shows only the steady line (8.6) and says so (8.7). The time line
counts up in whole minutes and never sets a target.

| # | Where | Text | Keep / Change / Cut |
|---|---|---|---|
| 8.1 | Button on Next meal | "This meal is hard" / under it: "Your plan, one line at a time" | |
| 8.2 | Heading | "Dinner, one line at a time" (meal name changes) | |
| 8.3 | Over each line | "From your clinician", and "2 of 4" | |
| 8.4 | Buttons | "Next line", "Back", and on the last line "Start again" | |
| 8.5 | Under the heading | "Just sat down", then "At the table 6 min" | |
| 8.6 | No lines yet: heading and line | "Dinner is hard right now" / "Hard meals happen in recovery. You don't have to work this out alone." | |
| 8.7 | No lines yet | "Your clinician hasn't written lines to read at the table yet. Ask about it at your next session." | |
| 8.8 | Bottom | "The meal is over" / "Then write down how it went." (opens the log for this meal) | |

- **Q13.** Is a count of time at the table helpful, or could it add pressure? Should it be hidden by default?
- **Q14.** With no clinician lines, should the app show a few general FBT lines (written with a clinician)
  instead of only saying none are written yet?
- **Q15.** Should "This meal is hard" also tell the other parent (planned with several caregivers), and should
  a clinician see how often it was used?
